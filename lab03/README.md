### Задание 1 **(3)**

- **Тип в программировании** — множество допустимых значений данных и операций, которые можно выполнять над этими значениями. Тип определяет способ хранения и интерпретации данных в программе.

- **Статическая типизация** — система типизации, при которой типы переменных и выражений определяются во время компиляции программы. Большинство ошибок несовместимости типов обнаруживается до запуска программы.

- **Динамическая типизация** — система типизации, при которой тип значения определяется во время выполнения программы. Переменная может последовательно ссылаться на значения разных типов.

- **Неявная типизация** — определение типа переменной компилятором автоматически на основании значения или выражения, которым она инициализируется. Например, в C++ для этого используется `auto`.

- **Явное преобразование типа** — преобразование значения одного типа в другой, которое явно задается программистом. В C++ примером является `static_cast<int>(value)`.

- **Неявное преобразование типа** — автоматическое преобразование одного типа в другой, выполняемое компилятором без явного указания со стороны программиста.

- **Сильная типизация** — система типизации, в которой операции между несовместимыми типами строго ограничены и обычно требуют явного преобразования типов.

- **Слабая типизация** — система типизации, допускающая больше автоматических преобразований между различными типами данных.

### Задание 2 **(3)**

#### Преобразования при присваивании

При присваивании значение правой части выражения неявно преобразуется к типу переменной в левой части, если такое преобразование разрешено языком.

```cpp
double d = 5;      // int преобразуется в double
int x = 3.8;       // double преобразуется в int, дробная часть отбрасывается
char c = 65;       // int преобразуется в char
```

При преобразовании вещественного типа в целочисленный дробная часть отбрасывается.

При преобразовании целого значения в вещественное числовое значение обычно сохраняется, но для больших чисел возможна потеря точности.

При преобразовании между целочисленными типами результат зависит от диапазона целевого типа.

#### Преобразования при арифметических действиях

Перед выполнением арифметической операции операнды приводятся к совместимому типу.

Для небольших целочисленных типов (`bool`, `char`, `short`) обычно выполняются целочисленные продвижения до `int` или `unsigned int`.

```cpp
short a = 10;
short b = 20;

auto result = a + b;
```

Тип `result` обычно будет `int`.

Если один операнд имеет вещественный тип, второй преобразуется к соответствующему вещественному типу.

```cpp
int x = 5;
double y = 2.0;

auto result = x / y;
```

`x` преобразуется в `double`, поэтому результат равен `2.5`.

При совместном использовании знаковых и беззнаковых целых типов применяются правила обычных арифметических преобразований. В некоторых случаях знаковое значение преобразуется в беззнаковое, что может привести к неожиданному результату.

#### Преобразования с логическими значениями

Тип `bool` может быть неявно преобразован в целочисленный тип:

```text
true  -> 1
false -> 0
```

Например:

```cpp
int x = true;
int y = false;
```

После преобразования `x == 1`, а `y == 0`.

Числовое значение также может быть преобразовано в `bool`:

```cpp
bool a = 0;
bool b = 10;
bool c = -5;
```

Значение `0` преобразуется в `false`, а любое ненулевое значение — в `true`.

### Задание 3 **(2)**

Один из примеров различия C++ и Java связан с преобразованием целого числа в логическое значение.

В C++:

```cpp
#include <iostream>

int main() {
    int x = 5;

    if (x) {
        std::cout << "true\n";
    }

    return 0;
}
```

Программа корректна. Значение `5` неявно преобразуется к `bool`. Любое ненулевое значение считается `true`.

Похожий код в Java:

```java
public class Main {
    public static void main(String[] args) {
        int x = 5;

        if (x) {
            System.out.println("true");
        }
    }
}
```

не компилируется, поскольку условие `if` в Java должно иметь тип `boolean`. Целое число нельзя автоматически использовать в качестве логического значения.

Другой пример — преобразование логического значения в число.

C++:

```cpp
#include <iostream>

int main() {
    bool value = true;
    int x = value;

    std::cout << x << std::endl;
}
```

Результат:

```text
1
```

`true` автоматически преобразуется в `1`.

В Java аналогичный код:

```java
public class Main {
    public static void main(String[] args) {
        boolean value = true;
        int x = value;
    }
}
```

вызывает ошибку компиляции, так как `boolean` нельзя преобразовать в `int`.

Еще один пример:

C++:

```cpp
#include <iostream>

int main() {
    int x = 10;

    bool result = x;

    std::cout << result << std::endl;
}
```

Результат:

```text
1
```

Java:

```java
public class Main {
    public static void main(String[] args) {
        int x = 10;
        boolean result = x;
    }
}
```

Такой код не компилируется.

Таким образом, C++ допускает ряд неявных преобразований между числовыми и логическими типами, которые Java запрещает.

### Задание 4 **(1)**

```cpp
#include <iostream>
#include <typeinfo>

int main() {
    bool x = true, y = false;

    auto a = x & y;
    std::cout << typeid(a).name() << std::endl;

    auto b = x && y;
    std::cout << typeid(b).name() << std::endl;

    return 0;
}
```

В выражении:

```cpp
x & y
```

используется побитовый оператор `&`.

Перед его выполнением значения типа `bool` проходят целочисленное продвижение и преобразуются в `int`.

Получается:

```cpp
1 & 0
```

Результат равен `0`, а тип выражения — `int`.

Следовательно:

```cpp
auto a = x & y;
```

переменная `a` имеет тип:

```text
int
```

В выражении:

```cpp
x && y
```

используется логический оператор `&&`. Результатом логического оператора всегда является значение типа `bool`.

Поэтому:

```cpp
auto b = x && y;
```

переменная `b` имеет тип:

```text
bool
```

Итог:

```text
a — int
b — bool
```

Конкретные строки, которые выводит `typeid(...).name()`, зависят от компилятора. Например, GCC часто выводит `i` для `int` и `b` для `bool`.

### Задание 5. **(2)**

#### `typedef`

`typedef` позволяет создать дополнительное имя существующего типа.

```cpp
#include <iostream>

typedef unsigned long UserId;

int main() {
    UserId id = 12345;

    std::cout << id << std::endl;

    return 0;
}
```

Здесь `UserId` является дополнительным именем типа `unsigned long`. Такое обозначение делает назначение переменной понятнее.

#### `auto`

`auto` позволяет компилятору автоматически определить тип переменной.

```cpp
#include <iostream>

int main() {
    auto age = 20;
    auto price = 15.5;
    auto name = "Alex";

    std::cout << age << std::endl;
    std::cout << price << std::endl;
    std::cout << name << std::endl;

    return 0;
}
```

Для `age` будет выведен тип `int`, для `price` — `double`, а `name` будет указателем на константные символы.

#### `decltype`

`decltype` позволяет определить тип выражения без его вычисления.

```cpp
#include <iostream>

int main() {
    int x = 10;
    double y = 2.5;

    decltype(x + y) result = x + y;

    std::cout << result << std::endl;

    return 0;
}
```

Поскольку при сложении `int` и `double` значение `x` преобразуется в `double`, тип `x + y` — `double`. Следовательно, `result` также имеет тип `double`.

#### `static_cast`

`static_cast` используется для явного преобразования типов.

```cpp
#include <iostream>

int main() {
    int x = 7;
    int y = 2;

    double result = static_cast<double>(x) / y;

    std::cout << result << std::endl;

    return 0;
}
```

Без преобразования выражение `x / y` выполняло бы целочисленное деление и дало бы `3`.

После:

```cpp
static_cast<double>(x)
```

вычисление происходит в типе `double`, поэтому результат равен:

```text
3.5
```

#### `sizeof`

Оператор `sizeof` возвращает размер типа или объекта в байтах.

```cpp
#include <iostream>

int main() {
    int x = 10;
    double y = 5.5;

    std::cout << sizeof(x) << std::endl;
    std::cout << sizeof(y) << std::endl;

    return 0;
}
```

Размер конкретных типов зависит от реализации и платформы, хотя на распространенных системах `int` часто занимает 4 байта, а `double` — 8 байт.

### Задание 6 **(2)**

```cpp
int a = -1, b = 1;
unsigned int c = 1;

std::cout << a * b << std::endl;
std::cout << a * c << std::endl;
```

В первом выражении:

```cpp
a * b
```

оба операнда имеют тип `int`.

Поэтому вычисляется:

```text
-1 * 1 = -1
```

и программа выводит:

```text
-1
```

Во втором выражении:

```cpp
a * c
```

используются `int` и `unsigned int`.

При обычных арифметических преобразованиях на типичной платформе, где эти типы имеют одинаковый ранг и диапазон `int` не способен представить все значения `unsigned int`, значение `a` преобразуется в `unsigned int`.

То есть `-1` становится максимальным значением `unsigned int`.

Для 32-битного `unsigned int`:

```text
-1 -> 4294967295
```

После умножения на `1` результат остается:

```text
4294967295
```

Поэтому типичный вывод:

```text
-1
4294967295
```

Если заменить типы следующим образом:

```cpp
short a = -1, b = 1;
unsigned short c = 1;
```

то перед арифметической операцией для `short` и `unsigned short` выполняются целочисленные продвижения.

На обычной системе, где `int` способен представить все значения `unsigned short`, оба операнда преобразуются в `int`.

Поэтому:

```cpp
a * b
```

дает:

```text
-1
```

и:

```cpp
a * c
```

также дает:

```text
-1
```

Типичный результат:

```text
-1
-1
```

### Задание 7 **(2)**

```cpp
int x = 7, y = 4;
long double d = 0.25;

cout << (x / y) / d << endl;
cout << (x / d) / y << endl;

long a = 200000, b = 200000;
long long c = 200000;

std::cout << (a * b) * c << std::endl;
std::cout << a * (b * c) << std::endl;
```

В выражении:

```cpp
(x / y) / d
```

сначала вычисляется:

```cpp
x / y
```

Обе переменные имеют тип `int`, поэтому выполняется целочисленное деление:

```text
7 / 4 = 1
```

Затем:

```text
1 / 0.25 = 4
```

Итог:

```text
4
```

В выражении:

```cpp
(x / d) / y
```

сначала вычисляется:

```cpp
x / d
```

Так как `d` имеет тип `long double`, значение `x` преобразуется к `long double`.

Получается:

```text
7 / 0.25 = 28
```

Затем:

```text
28 / 4 = 7
```

Итог:

```text
7
```

Таким образом, результаты различаются из-за того, что в первом случае сначала происходит целочисленное деление с потерей дробной части.

Для выражения:

```cpp
(a * b) * c
```

сначала вычисляется:

```cpp
a * b
```

Обе переменные имеют тип `long`, поэтому результат этого промежуточного выражения также имеет тип `long`.

Если `long` достаточно велик, чтобы представить значение:

```text
200000 * 200000 = 40000000000
```

вычисление пройдет корректно. На системах, где `long` является 32-битным, возникает переполнение знакового целого типа, а такое переполнение в C++ приводит к неопределенному поведению.

В выражении:

```cpp
a * (b * c)
```

сначала вычисляется:

```cpp
b * c
```

Здесь участвуют `long` и `long long`, поэтому `b` преобразуется к `long long`.

Промежуточный результат имеет тип:

```text
long long
```

После этого `a` также преобразуется в `long long`, и второе умножение выполняется в `long long`.

Математический результат:

```text
200000 * 200000 * 200000 = 8000000000000000
```

Он помещается в типичный 64-битный `long long`.

Следовательно, расстановка скобок влияет не только на порядок вычислений, но и на тип промежуточного результата.

### Задание 8 **(2)**

Выражение:

```cpp
(x == y) + (x == z) == true
```

сначала вычисляет два сравнения:

```cpp
x == y
x == z
```

Каждое из них имеет тип `bool`.

При сложении значения `bool` проходят целочисленное продвижение:

```text
false -> 0
true  -> 1
```

Поэтому сумма может быть:

```text
0
1
2
```

Затем она сравнивается с:

```cpp
true
```

При сравнении `true` преобразуется в целое значение:

```text
1
```

Фактически выражение эквивалентно:

```cpp
(x == y) + (x == z) == 1
```

Следовательно, выражение истинно только тогда, когда ровно одно из двух сравнений истинно.

Все случаи:

```text
x == y и x != z
```

или:

```text
x != y и x == z
```

Иными словами:

```text
x равен ровно одной из переменных y и z.
```

Если все три значения равны, оба сравнения дают `true`, сумма равна `2`, поэтому итоговое выражение будет `false`.

Если `x` не равен ни `y`, ни `z`, сумма равна `0`, и результат также `false`.

### Задание 9 **(2)**

#### Python

В Python:

```python
x == y == z
```

является цепочечным сравнением.

Оно эквивалентно по смыслу выражению:

```python
x == y and y == z
```

Например:

```python
x = 5
y = 5
z = 5

print(x == y == z)
```

Результат:

```text
True
```

Если:

```python
x = 5
y = 5
z = 1
```

результат:

```text
False
```

#### Java

В Java выражение:

```java
x == y == z
```

для переменных типа `int` не компилируется.

Оператор `==` вычисляется слева направо:

```java
(x == y) == z
```

Первое сравнение:

```java
x == y
```

дает значение типа `boolean`.

После этого фактически получается попытка выполнить:

```text
boolean == int
```

что в Java запрещено.

Правильная запись проверки равенства трех чисел:

```java
x == y && y == z
```

#### C++

В C++ выражение:

```cpp
x == y == z
```

разбирается как:

```cpp
(x == y) == z
```

Первое сравнение:

```cpp
x == y
```

возвращает `bool`.

При сравнении с целым `z` значение `bool` преобразуется в целое:

```text
false -> 0
true  -> 1
```

Поэтому фактически проверяется:

```cpp
0 == z
```

или:

```cpp
1 == z
```

Например:

```cpp
int x = 5;
int y = 5;
int z = 1;

std::cout << (x == y == z);
```

Сначала:

```text
5 == 5 -> true
```

Затем:

```text
true -> 1
1 == 1 -> true
```

Результат:

```text
1
```

Хотя числа `5`, `5` и `1` не равны между собой.

Для проверки равенства трех чисел в C++ следует писать:

```cpp
x == y && y == z
```

Таким образом:

```text
Python: цепочечное сравнение, проверяются оба равенства.
Java: ошибка компиляции.
C++: сначала x == y, затем результат bool сравнивается с z.
```

### Задание 10 **(1))**

```python
text1 = "Hello"
text2 = ""

if text1:
    print("text1 преобразована в True")
else:
    print("text1 преобразована в False")

if text2:
    print("text2 преобразована в True")
else:
    print("text2 преобразована в False")
```

Результат:

```text
text1 преобразована в True
text2 преобразована в False
```

В Python строку можно использовать непосредственно в логическом контексте, например в условии `if`.

Непустая строка рассматривается как истинное значение:

```python
bool("Hello") == True
```

Пустая строка рассматривается как ложное значение:

```python
bool("") == False
```

Таким образом, при вычислении условия Python автоматически использует логическую истинность объекта строки.
