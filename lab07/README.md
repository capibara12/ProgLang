### Задание 1 **(2)**

*Оцените работу следующих фрагментов программ. Какие из них обладают неоднозначным поведением? Почему?*

```cpp
int x=10, y=3;
std::cout << std::min(x=15, x+y);
```

```cpp
int x=10, y=3;
x=15, y+=x, x+=y;
```

```cpp
int x=10, y=9;
if (x>y++ && y++>9)
  cout << "yes" << endl;
cout << y;
```

*Тексты программ разместите в папке с номером задания.*

**Ответ:**

В первом фрагменте результат зависит от порядка вычисления аргументов `std::min`. Если сначала вычисляется `x+y`, получается 13, и `min(15,13)` возвращает 13. Если сначала выполняется `x=15`, затем `x+y` равно 18, и `min(15,18)` возвращает 15. В C++17 и новее аргументы функции вычисляются без взаимного наложения, но порядок между ними не задан, поэтому возможны 13 или 15. В старых стандартах такое изменение и чтение `x` могли давать неопределённое поведение.

Во втором фрагменте используется оператор запятая, который выполняет действия слева направо:

- `x=15` — теперь x равно 15;
- `y+=x` — y становится 18;
- `x+=y` — x становится 33.

Здесь порядок известен, неоднозначности нет. В конце `x=33`, `y=18`.

В третьем фрагменте `y++` сначала даёт старое значение, а затем увеличивает `y`. Сначала проверяется `10>9`, это истина, и `y` становится 10. Затем проверяется `10>9`, это тоже истина, и `y` становится 11. Поэтому программа выводит:

```text
yes
11
```

Оператор `&&` вычисляет левую часть перед правой. Если левая часть ложная, правая вообще не выполняется. Поэтому здесь результат определён.

Для проверки я использовал полные программы, добавляя `#include <iostream>`, `#include <algorithm>` для первого примера и функцию `main()`.

### Задание 2 **(2)**

*Как записать следующие строки программы на С++ в виде одного выражения? Приведите несколько способов, в том числе с использованием операторов инкремента. Проверьте работу написанных программ.*

```cpp
x=x+1;
z=z+2*x+3*y;
y=y+1;
```

*Тексты программ разместите в папке с номером задания.*

**Ответ:**

Я записал эти действия в одном выражении несколькими способами:

```cpp
(++x, z += 2*x + 3*y, ++y);
```

```cpp
(x += 1, z = z + 2*x + 3*y, y += 1);
```

```cpp
z += 2*(++x) + 3*y, y++;
```

Во всех случаях сначала увеличивается `x`, потом изменяется `z`, и только потом увеличивается `y`. Оператор запятая позволяет выполнить действия в нужной последовательности. В третьем варианте `++x` увеличивает `x` до использования в вычислении `z`, а `y++` выполняется уже после него.

Проверочная программа:

```cpp
#include <iostream>
int main() {
    int x=1, y=2, z=3;
    (++x, z += 2*x + 3*y, ++y);
    std::cout << x << " " << y << " " << z;
}
```

Результат: `2 3 13`. Исходные три строки дают тот же ответ.

### Задание 4 **(2)**

*Почему присваивание* `(++x)=y` *является синтаксически правильным, а* `(x++)=y` *— нет? Запишите текст сообщения об ошибке, переведите и объясните его.*

**Ответ:**

Проверял на таком коде:

```cpp
int main() {
    int x=1, y=2;
    (++x)=y;  // работает
    (x++)=y;  // ошибка
}
```

GCC выдал сообщение:

```text
error: lvalue required as left operand of assignment
```

Перевод: «В левой части присваивания требуется lvalue».

По лекции lvalue — это выражение, которое обозначает объект, которому можно присвоить значение, если он не константный. Префиксный инкремент `++x` возвращает саму переменную `x`, поэтому результат можно использовать слева от `=`. Постфиксный `x++` возвращает старое значение, а не переменную, поэтому присваивать ему нельзя.

### Задание 5 **(2)**

*Программисты на Python для обмена значений двух переменных часто пишут строку:*

```python
a,b = b,a
```

*Проверьте, будет ли аналогичная строка на С++ (с точкой с запятой в конце) являться синтаксически правильной? Будет ли она обменивать значения переменных? Как в языке С++ вычисляется это выражение?*

**Ответ:**

Проверил программу:

```cpp
#include <iostream>
int main() {
    int a=2, b=5;
    a,b = b,a;
    std::cout << a << " " << b;
}
```

Она компилируется, но выводит `2 5`, а не `5 2`.

В C++ запятая — отдельный оператор с самым низким приоритетом. Поэтому выражение разбирается как `(a, b=b, a)`. Первое `a` просто вычисляется, но ничего не меняет. Потом выполняется `b=b` и ничего не меняет. Последнее `a` тоже ничего не меняет.

Таким образом, значения не обмениваются. Для настоящего обмена переменных в C++ можно написать:

```cpp
std::swap(a,b);
```

Или использовать временную переменную:

```cpp
int t=a;
a=b;
b=t;
```

### Задание 6 **(2)**

*Проверьте работу следующего фрагмента программы.*

```cpp
std::string s;
for (int i=0; i<1000000; i++)
   s += 'a';
std::cout << s.size();
```

*Измените третью строку на:*

```cpp
s=s+'a';
```

*Изменится ли что-нибудь в ее работе? Объясните результат.*

**Ответ:**

Я сравнил два способа. Оба создают строку из миллиона букв `a` и выводят `1000000`.

```cpp
#include <iostream>
#include <string>
#include <chrono>
int main() {
    std::string s;
    auto start=std::chrono::steady_clock::now();
    for (int i=0; i<1000000; i++)
        s += 'a'; // для второго варианта заменить на s=s+'a';
    auto finish=std::chrono::steady_clock::now();
    std::cout << s.size() << "\n";
    std::cout << std::chrono::duration<double>(finish-start).count();
}
```

Разница в скорости: `s += 'a'` добавляет символ к существующей строке, обычно не создавая полную копию на каждом шаге. При `s=s+'a'` обычно создаётся новая временная строка из старой строки и нового символа, затем результат присваивается `s`. Из-за многочисленных копирований второй вариант обычно заметно медленнее. Точное время зависит от компьютера и настроек компиляции.

### Задание 7 **(2)**

*Как работает следующая программа? Как зависит результат от исходного значения?*

```cpp
int x;
std::cin >> x;
x-->0 && x-->0 && x-->0 && x-->0 && x-->0;
std::cout << x;
```

**Ответ:**

Запись `x-->0` на самом деле означает `x-- > 0`: сравнение старого значения `x` с нулём, после которого `x` уменьшается на единицу.

Всего записано пять проверок через `&&`. Они идут слева направо. Как только проверка оказывается ложной, остальные не выполняются.

Для обычных входных целых чисел результат можно определить так:

- если `x` изначально больше или равно 5, программа уменьшит его на 5;
- если `x` от 0 до 4, программа остановится, когда выполнится проверка нуля, и выведет -1;
- если `x` отрицательное, первая проверка сразу будет ложной, но `x` всё равно уменьшится на 1.

Например, `8` превращается в `3`, `3` — в `-1`, `0` — в `-1`, `-2` — в `-3`. Для минимального значения `int` уменьшение на единицу приведёт к переполнению, то есть к неопределённому поведению.

### Задание 2 **(10)**

*Язык С++ позволяет записывать достаточно странные конструкции. Следующая программа обладает неопределенным поведением. После компиляции с использованием Gnu C++ (g++) эта программа выводит числа 4 и 11. Рассмотрите ассемблерный код и объясните, каким образом был получен ответ 11.*

```cpp
int x, y;
y = (x=1) + (x=2) + (x=3) + (x=4);
std::cout << x << " " << y;
```

**Ответ:**

Я проверил этот пример на GCC 14.2 без оптимизации. Получилось `4 11`. На Clang 17 в моём эксперименте получилось `4 10`. Это нормально для программы с неопределённым поведением: в одном выражении переменная `x` изменяется несколько раз без нужного порядка между всеми действиями.

Для получения ассемблерного текста использовал команду:

```bash
g++ -std=c++17 -O0 -S -masm=intel main.cpp -o main.s
```

Здесь `-O0` отключает оптимизацию, `-S` создаёт ассемблерный текст, а `-masm=intel` выбирает более удобный для чтения синтаксис.

Главные строки полученного ассемблерного кода:

```asm
mov DWORD PTR -4[rbp], 1
mov DWORD PTR -4[rbp], 2
mov eax, DWORD PTR -4[rbp]
lea edx, [rax+rax]
mov DWORD PTR -4[rbp], 3
mov eax, DWORD PTR -4[rbp]
add edx, eax
mov DWORD PTR -4[rbp], 4
mov eax, DWORD PTR -4[rbp]
add eax, edx
mov DWORD PTR -8[rbp], eax
```

Сначала компилятор записал в `x` значение 1, а следом перезаписал его значением 2. Затем команда `lea` вычислила сумму `2+2=4`. После записи `x=3` добавилась тройка, получилось 7. После записи `x=4` добавилась четвёрка, получилось 11. В итоге `x=4`, `y=11`.

Здесь нельзя говорить, что C++ всегда должен считать именно так. Это только конкретный вариант машинных команд, выбранный GCC. Правильнее не менять одну переменную несколько раз в одном арифметическом выражении.

### Задание 3 **(10)**

*Прочитайте в стандарте языка С++ правила вычисления результата для тернарного оператора* **?:**. *Напишите примеры для каждого пункта правил.*

**Ответ:**

Тернарный оператор записывается так:

```cpp
условие ? значение_если_истина : значение_если_ложь
```

По лекции сначала проверяется условие, а затем выполняется только одна из двух частей. Для остальных правил я дополнительно использовал справочник по C++: https://en.cppreference.com/w/cpp/language/operator_other .

**1. Выбирается только одна ветка.**

```cpp
int x=5, y=0;
int z = x>0 ? ++x : ++y;
std::cout << x << " " << y << " " << z;
```

Результат `6 0 6`. Увеличилась только `x`.

**2. Обе ветки имеют тип void.**

```cpp
bool ok=true;
ok ? (void)std::puts("yes") : (void)std::puts("no");
```

Результат оператора тоже имеет тип `void`, то есть не возвращает обычного значения.

**3. В одной ветке может стоять throw.**

```cpp
int x=10;
int z = x>0 ? x : throw 1;
```

Если условие ложное, выполняется `throw`, то есть выбрасывается исключение. В примере `z=10`.

**4. Если обе ветки — изменяемые переменные одного типа, результат может быть lvalue.**

```cpp
int a=1, b=2;
(a<b ? a : b)=10;
std::cout << a;
```

Результат `10`: присваивание произошло переменной `a`.

**5. Для разных числовых типов выбирается общий тип.**

```cpp
bool ok=true;
auto x = ok ? 3 : 2.5;
```

Тип `x` будет `double`, значение — `3.0`.

**6. Классы могут преобразовываться к общему типу.**

```cpp
#include <string>
bool ok=true;
std::string s = ok ? std::string("hello") : "bye";
```

Вторую ветку можно преобразовать в `std::string`. Получится строка `hello`.

**7. Ветки могут содержать указатели, включая nullptr.**

```cpp
int x=5;
bool ok=false;
int* p = ok ? &x : nullptr;
```

Здесь `p` будет нулевым указателем.

**8. Если одна ветка возвращает несовместимое значение void, программа не компилируется.**

```cpp
bool ok=true;
// auto x = ok ? 10 : (void)0; // ошибка
```

В одной ветке число, а в другой — выражение `void`, которое не является `throw`.

**9. Можно использовать битовые поля и правила их типов.**

```cpp
struct Bits { unsigned a:3; unsigned b:3; } v{1,2};
bool ok=true;
(ok ? v.a : v.b)=3;
```

Здесь обе ветки выбирают битовые поля одинакового типа, и можно изменить выбранное поле.

**10. При одинаковых типах результат сохраняет их категорию, если позволяют правила.**

```cpp
int a=1, b=2;
int&& r = true ? static_cast<int&&>(a) : static_cast<int&&>(b);
```

Оба выражения имеют категорию `xvalue`, поэтому результат тоже относится к ней.

**11. Если типы указателей различаются, может быть найден общий тип указателя.**

```cpp
int x=1;
bool ok=true;
const int* p = ok ? &x : static_cast<const int*>(&x);
```

Результат можно использовать как указатель на константный `int`.

**12. Тернарные операторы можно вкладывать друг в друга.**

```cpp
int x=7;
const char* s = x<0 ? "negative" : x==0 ? "zero" : "positive";
```

Получится `positive`. Если условие первое ложное, проверяется второе.

Итог: оператор `?:` позволяет выбрать одно из двух выражений. Его результат зависит не только от условия, но и от типов и категорий значений обеих веток.

## Задание 2

### Код программы

```python
t = int(input())

for i in range(t):
    n = int(input())
    p, q = map(int, input().split())

    s = "0."

    for j in range(n):
        p = p * 2
        s += str(p // q)
        p = p % q

    print(s)
```

### Объяснение

Я написал программу для перевода обыкновенной дроби в двоичную систему счисления.

Сначала считываю число `t`. Оно показывает, сколько дробей нужно обработать.

Далее для каждой дроби считываю:

- `n` — сколько двоичных знаков нужно вывести;
- `p` — числитель дроби;
- `q` — знаменатель дроби.

С помощью `map(int, input().split())` считываю два числа из одной строки.

Создаю строку `s = "0."`, в которую буду записывать результат.

Затем запускаю цикл `for j in range(n)`, который выполняется `n` раз.

На каждом шаге умножаю числитель на 2:

```python
p = p * 2
```

После этого с помощью `p // q` получаю следующую цифру двоичной записи.

Команда:

```python
s += str(p // q)
```

добавляет эту цифру в конец строки. Функция `str()` превращает число в текст.

Затем нахожу остаток:

```python
p = p % q
```

Оператор `%` возвращает остаток от деления. Он нужен для вычисления следующей двоичной цифры.

В конце вывожу полученную запись.

Пример:

Ввод:
```text
1
4
1 2
```

Вывод:
```text
0.1000
```

Дробь `1/2` в двоичной системе равна `0.1`. Поскольку нужно вывести четыре цифры после точки, программа добавляет нули.

Программа рассчитана на дроби, у которых `0 <= p < q` и `q > 0`.

## Задание 3

```python
t = int(input())

for i in range(t):
    a, b, c, d, e, f, g, h = map(int, input().split())

    x = (a * d + c * b) * f * h
```

### Объяснение

Я написал программу, которая сравнивает две суммы обыкновенных дробей.

Первая сумма:

`a/b + c/d`

Вторая сумма:

`e/f + g/h`

Сначала считываю количество проверок `t`.

Затем в цикле получаю восемь целых чисел, которые используются как числители и знаменатели дробей.

Чтобы сравнить дроби, я решил не переводить их в десятичные числа, а использовать умножение.

Сначала вычисляю:

```python
x = (a * d + c * b) * f * h
```

Здесь я складываю первые две дроби через общий знаменатель и умножаю результат на знаменатели второй суммы.

Затем вычисляю:

```python
y = (e * h + g * f) * b * d
```

Аналогично вычисляю значение для второй суммы.

После этого сравниваю `x` и `y`.

Если первая сумма больше второй, вывожу `1`.

Если первая сумма меньше второй, вывожу `-1`.

Если суммы равны, вывожу `0`.

Для проверки использую условия `if`, `elif` и `else`.

Параметр `end=" "` нужен, чтобы результаты выводились в одну строку через пробел.

Пример:

Ввод:
```text

1 2 1 2 3 4 1 4
```

Вывод:
```text

```

В первом случае первая сумма больше, во втором меньше, а в третьем обе суммы равны.

Такой способ позволяет сравнивать дроби точно, без ошибок округления. Для правильной работы сравнения знаменатели должны быть положительными.

## Задание 4

### Код программы

```python
n = int(input())
a = list(map(int, input().split()))

s = ""

for x in a:
    b = bin(x)[2:]
    y = len(b)
    z = len(bin(y)[2:]) - 1

    s += "0" * z + bin(y)[2:] + b[1:]

print(s)
```

### Объяснение

Я написал программу, которая кодирует положительные целые числа в двоичном виде с помощью дельта-кода Элиаса.

Сначала считываю количество чисел `n`.

Затем с помощью:

```python
a = list(map(int, input().split()))
```

считываю сами числа и записываю их в список `a`.

Создаю пустую строку `s`, в которую буду добавлять закодированные числа.

Далее с помощью цикла `for x in a` перебираю все числа из списка.

Сначала перевожу число в двоичную систему:

```python
b = bin(x)[2:]
```

Функция `bin()` возвращает двоичную запись числа, которая начинается с `0b`.

Запись `[2:]` убирает первые два символа, оставляя только нули и единицы.

Затем нахожу длину двоичной записи:

```python
y = len(b)
```

Функция `len()` возвращает количество символов.

После этого вычисляю:

```python
z = len(bin(y)[2:]) - 1
```

Здесь определяю, сколько нулей нужно поставить перед двоичной записью длины числа.

Далее собираю закодированную запись:

```python
s += "0" * z + bin(y)[2:] + b[1:]
```

Она состоит из трёх частей:

1. Нули в начале.
2. Двоичная запись длины числа.
3. Двоичная запись самого числа без первой единицы.

Все закодированные числа объединяю в одну строку.

В конце вывожу эту строку с помощью `print()`.

Пример:

Ввод:
```text
3
1 2 5
```

Для числа `1` получается код `1`.

Для числа `2` получается код `0100`.

Для числа `5` получается код `01101`.

Общий вывод:
```text
1010001101
```

Таким способом можно записать последовательность положительных чисел в виде одной строки из нулей и единиц.

## Задание 5

### Код программы

```python
s = input()
i = 0
a = []

while i < len(s):
    z = 0

    while s[i] == "0":
        z += 1
        i += 1

    y = int(s[i:i + z + 1], 2)
    i += z + 1

    x = int("1" + s[i:i + y - 1], 2)
    i += y - 1

    a.append(x)

print(len(a))
print(*a)
```

### Объяснение

Я написал программу, которая выполняет обратное действие к предыдущему заданию.

Она получает строку из нулей и единиц, закодированную с помощью дельта-кода Элиаса, и восстанавливает исходные числа.

Сначала с помощью `input()` считываю двоичную строку `s`.

Создаю переменную `i = 0`. Она будет показывать, на каком месте строки я сейчас нахожусь.

Также создаю пустой список:

```python
a = []
```

В него буду записывать восстановленные числа.

Далее запускаю цикл:

```python
while i < len(s):
```

Он работает, пока не будет обработана вся строка.

Для каждого числа сначала обнуляю счётчик `z`.

Затем выполняю:

```python
while s[i] == "0":
    z += 1
    i += 1
```

Этот цикл считает количество нулей в начале очередного закодированного числа.

После этого выполняю:

```python
y = int(s[i:i + z + 1], 2)
```

Здесь беру следующие `z + 1` символов и перевожу их из двоичной системы в десятичную.

Число `2` в функции `int()` означает, что исходная запись двоичная.

Полученное значение `y` показывает длину двоичной записи исходного числа.

Затем передвигаю позицию `i` дальше:

```python
i += z + 1
```

После этого восстанавливаю само число:

```python
x = int("1" + s[i:i + y - 1], 2)
```

Сначала добавляю единицу, потому что при кодировании первая единица двоичной записи убиралась.

Затем добавляю оставшиеся `y - 1` символов и перевожу полученную двоичную запись в обычное число.

После этого перемещаю позицию дальше:

```python
i += y - 1
```

Готовое число добавляю в список:

```python
a.append(x)
```

Когда вся строка обработана, вывожу:

```python
print(len(a))
print(*a)
```

Первая команда выводит количество восстановленных чисел.

Вторая выводит сами числа через пробел.

Звёздочка `*` перед `a` позволяет передать элементы списка в `print()` по отдельности.

Пример:

Ввод:
```text
1010001101
```

Вывод:
```text
3
1 2 5
```

Программа восстановила три числа, которые были закодированы в предыдущем задании.

Таким образом, четвёртая программа кодирует положительные числа, а пятая декодирует их обратно.
